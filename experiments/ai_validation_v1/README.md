# 추가 검증 v1 — 가중치 고정 개발 진단

2026-09-11, 입력 생성과 추가 추론 **이전**에 고정한 시험 계획.
제품 원본: `docs/caregiving_notebook_requirements.md`, 특히 §8.4.
이 시험은 임상 검수·의료 출시 승인에 해당하지 않는다.
`evaluation_eligible=false`, `medical_release_gate_result=false`를 유지한다.

## 실패 시나리오와 판정

1. **챗봇**: 학습한 표현에서 벗어나 날짜·항목을 잘못 추출하거나, 의료 질문에 기록 조회로 응답한다.
   새 합성 질문 120개(5언어 × 12종 × 2개)를 원본/SFT/증류에 동일하게 입력한다.
   문장 재표현·구조화·정정·날짜 누락·상대 날짜·잘못된 날짜·복수 대상·의료와 조회 혼합·다른 수첩·지시문 공격·없는 기록·부정 기록을 포함한다.
   현재 단일 조회 계약과 확장 요구(복수 대상, 다른 수첩)는 분리 집계한다.
   기대 답은 모델 출력이나 검색 함수로 만들지 않는다. 원문 값·기록 ID를 직접 고정한다.
   각 모델에서 같은 10개를 batch=1로 다시 실행하여 batch=4 결과와 비교한다.
   다른 수첩 기록을 실수로 전달했을 때의 경계도 별도 호스트 단위 시험으로 확인한다.
   실패는 숨기거나 프롬프트를 바꿔 재채점하지 않는다.

2. **OCR**: 추가 학습으로 영어, 소수점, 단위 대소문자, 부정 표현, 다른 글꼴의 인식이 퇴보한다.
   새 문자열 100개(언어별 20개), 이전 학습과 다른 글꼴 계열을 사용한다.
   원본/회전 4도/흐림 1.1/작은 글자/저대비 잡음의 5조건, 총 500개 줄 이미지를 고정한다.
   두 인식기의 원본/학습 CTC head를 동일한 특징과 디코더로 비교한다.
   언어·조건별 원문 일치, CER, 숫자·단위, 부정 표시 보존을 집계한다.
   변형 5개를 독립 표본 5개로 주장하지 않는다. 줄 이미지 결과로 검출·행 연결을 통과 처리하지 않는다.
   추가로 가능하면 실제 검출기를 통과하는 합성 다행 문서 시험을 별도 결과로 남긴다.

3. **음성**: 무음에서 문자를 만들거나, VAD가 조용한 발화를 버리거나, 숫자를 다른 값으로 바꾼다.
   고정된 공개 FLEURS 로컬 train 원본에서 기존 학습/평가의 문장 ID·정규화 전사·음성 해시를 제외한다.
   언어별 20개(가능하면 숫자·단위 포함 10개와 나머지 10개), 총 80개 새 녹음을 선택한다.
   언어별 앞 5개의 작은 음량(-30 dB)과 잡음(SNR 10 dB) 변형 40개를 추가한다.
   무음·백색 잡음·저주파 hum·chirp·충격음·진폭 변조 잡음의 비음성 대조군 24개를 생성한다.
   원본/LoRA 각각 기본 디코더와 첫 EOS 허용 디코더를 비교한다. 다른 디코딩 설정은 고정한다.
   Silero VAD v6.2의 고정 TorchScript 모델을 CPU에서 적용한다(임계값 0.5, 최소 음성 250 ms).
   VAD는 이 실험에서 전체 클립의 음성 유무만 판정한다. 통과한 클립은 자르지 않고 동일 ASR 출력을 사용한다.
   따라서 VAD 유무 결과는 재생성 없이 같은 출력에 gate를 적용하여 비교할 수 있다.
   CER, 중국어 간체 표시 정규화 CER, 숫자·단위 일치, 비음성 출력, 음성 누락을 각각 보고한다.
   원본 train에서 뽑은 새 로컬 평가 집합이며 공식 test나 화자 독립 평가라고 부르지 않는다.
   이 실험에서 숫자 표기 정규화로 strict 오류를 면제하지 않는다.

## 실행 및 증거

- 추가 학습, 앱 연결, 환자 데이터 접근, 외부 API 추론을 하지 않는다.
- 공개 VAD 자료 다운로드와 추론을 분리한다. 다운로드는 고정 revision·크기 제한·SHA-256·라이선스를 기록한다.
- 추론 중 Python 네트워크 연결 차단. GPU 작업 한 개, 할당 상한 50%, CPU 스레드 2. 사용자 앱을 종료하지 않는다.
- 기존 모델·입력·실행 결과를 덮어쓰지 않는다. 새 자료는 `data/ai-validation-v1`, 공개 보고서는 이 실험 폴더와 `docs`에 저장한다.
- 입력·실행 소스·결과 해시, 오류 기록, 실제 분모를 보존한다. 측정이 끝나지 않은 항목을 통과라고 쓰지 않는다.
- 데이터 중복 배제, 기준/예측 인자 순서, VAD 연속 구간, 무음/숫자 지표, 수첩 경계에 대한 자동 시험을 먼저 실행한다.
- 의료 회귀시험을 포함한 기존 Python 시험도 실행한다. 의료 근거 검색/RAG·임상 검수·실제 처방전/진료 대화·모바일 배포 검증은 별도 미완료 항목이다.
