# OCR 문서 대조시험

문서 입력 생성 및 검출 실행 전 고정(2026-09-11).
기존 새 줄 집합에서 언어별 0,1,16,19번 줄을 사용한다. 5변형 × 5언어 = 25문서, 100행.
각 페이지에 4행을 배치하며 행 간격은 14 px이다. 문서 배경은 흰색이다.
문서와 줄 시험은 같은 문자열을 공유한다. 별개 독립 표본이라고 합산하지 않는다.

고정 PP-OCRv5_mobile_det, CPU2, MKLDNN 꺼짐, 최대 변960,
pixel threshold0.3, box threshold0.6, unclip1.5로 검출한다.
정답은 배치된 줄 이미지의 사각형이다. 예측 polygon의 axis-aligned box와 IoU>=0.3인
쌍을 IoU 내림차순으로 한 번씩 연결한다. 누락과 중복/추가 박스를 별도 집계한다.
이는 합성 문서의 행 연결 진단이며 정밀한 글자 경계나 실제 처방전 검출 성능을 뜻하지 않는다.

검출된 사각형에서 perspective crop을 만든 후 동일한 48×320 인식 전처리를 사용한다.
실제 검출 crop을 원본/학습 head에 넣어 원문·숫자·단위·부정 표현을 비교한다.
검출하지 못한 행은 빈 예측으로 채점한다. 인식 실패를 검출 실패로 옮겨 숨기지 않는다.
파일/소스/설정 해시를 보존하며 모델이나 임계값은 결과를 보고 바꾸지 않는다.
