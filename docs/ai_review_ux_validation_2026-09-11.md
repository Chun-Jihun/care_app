# 언어 변경 중단·답변 출처·OCR 편집 검증

2026-09-11. 사전 시험은 [AI 검토 UI 안전 계획](./ai_review_ux_safety_plan.md)을 따른다.

## 구현 범위

- 설정과 잠금 화면의 언어 항목을 표시하면서 변경 동작을 비활성화했다. 준비 중 안내를 제공하고 기존 선택을 보존한다. 번역 카탈로그와 언어 저장 API는 향후 재개를 위해 유지한다.
- 챗봇 답변 옆 `근거 보기` → `답변의 근거`에서 참고 기록의 항목·시각·답변 당시 버전·사용한 내용을 확인하고 원본 기록으로 이동한다.
- 답변의 ID·버전과 실제 선택 수첩의 기록을 대조한다. 수정된 기록의 내용·시각을 예전 답변의 발췌로 표시하지 않으며, 삭제된 기록은 삭제 안내를 표시한다. 잠금 시 근거 화면을 제거하고 수첩 전환 시 원문을 숨긴다.
- OCR 화면은 원본 사진 확대, 수정 전 인식 결과 펼쳐 보기, 본문 수정, 선택 메모를 제공한다. 확인 후 본문과 메모를 기존 기록 편집기에 반영한다. 취소하면 기존 입력·확정 기록은 바뀌지 않는다. 편집기의 명시적 저장은 별도로 필요하다.
- 본문이 비거나 본문·메모·구분 문구 합계가 20,000자를 넘으면 반영을 차단한다. 긴 입력도 수정 후 진행할 수 있고 조용히 잘라 저장하지 않는다.

## 자동 검증 결과

- `flutter analyze --no-pub`: 문제 없음.
- `flutter test --no-pub --reporter expanded`: **82개 통과**. 기존 암호화 저장·백업·초안·잠금 회귀 포함.
- 출처 화면: 원문과 부정 표현 유지, 답변 버전 표시, 원본 이동, 수정·삭제·수첩 전환 및 잠금 시 노출 차단.
- OCR 화면: 수정과 메모 전달, 수정 전 인식 결과 보존, 취소 시 기존 입력 보존, 빈 본문 및 길이 초과 차단, 큰 글씨에서 조작 가능.
- 언어 메뉴: 다섯 기존 언어에서 잠금 화면 메뉴 표시·비활성화, 설정 메뉴 비활성화, 재실행 시 기존 선택 보존.
- 320×640·글자 200%에서 근거 화면과 OCR 입력 시험. 긴 텍스트를 입력했을 때 테스트 스크롤이 입력칸 내부로 들어가는 경우를 수정하고 입력칸 높이를 줄였다.
- 다섯 번역 카탈로그의 588개 키·자리표시자 및 생성 파일 일치 검증.

## 구분해야 할 한계

**실제 의료 문서의 페이지·절·발췌문 표시는 아직 연결되지 않았다.** 현재 운영 승인 KB가 없고 챗봇은 수첩 기록 조회만 수행한다. 근거 화면은 내 기록과 의료 문서 영역을 구분하고 의료 문서 미연결 상태를 알린다. 문서 제목·출처·의료 주장을 만들어 채우지 않는다. 승인 KB와 주장별 인용이 준비되면 자료명·기관·발행/개정일·페이지/절·근거문장·원문 링크·검수일을 표시해야 한다.

이번 변경은 모델 가중치·프롬프트·조회 정책·DB·백업 형식을 변경하지 않는다. 이전 네이티브 모델 검증 결과는 [기존 AI 실행 보고서](./mobile_ai_validation_2026-09-11.md)의 당시 빌드에 대한 결과다. 이번 UI 변경의 실물 휴대전화 조작과 iOS 빌드/실행은 수행하지 않았다.
