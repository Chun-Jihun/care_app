## 파일 선택 중 확인한 환경 문제

ADB로 복사한 폴더에서 처음에는 `ocr-ko.png`만 보인다고 사용자가 보고했다. 실제 `.careai` 파일 크기는 1,716,572,594바이트이며 복사 해시가 일치했다. 실행 중 선택 Intent는 `ACTION_OPEN_DOCUMENT`, `OPENABLE`, MIME `*/*`였다.

PNG에만 수행했던 파일 목록 등록을 모델 파일에도 요청한 뒤, 사용자가 폴더를 나갔다 다시 들어와 모델을 선택할 수 있었다. 앱의 형식 제한 변경 없이 해결했으며 앱 결함으로 확정하지 않는다. ADB로 만든 시험 파일의 목록 등록·선택창 갱신이 필요했던 재현 결과로 기록한다.

## 삼성 런처 위젯 미리보기 수정

같은 기기의 삼성 런처에서 위젯 추가 대화상자는 열렸으나 미리보기 영역에 `위젯을 추가할 수 없습니다.`가 표시됐다. 실제 추가 버튼으로 홈에 등록한 위젯에는 요약이 표시됐다. 앱의 추가 요청은 미리보기 인수를 전달하지 않았고 위젯 메타데이터에도 미리보기 레이아웃이 없었다.

실제 위젯과 같은 레이아웃을 `previewLayout`과 추가 요청의 `EXTRA_APPWIDGET_PREVIEW`에 연결했다. 미리보기에는 앱 이름과 고정 설명만 들어간다. [Android 위젯 미리보기 문서](https://developer.android.com/develop/ui/views/appwidgets/previews)

- 수정 debug APK SHA-256 `9F5BD7A2B6754DC7AFA497E75A5BED50D59FB6BFDBACE26286C5C21BB7C54F49`.
- 동일한 인증서 확인 후 `install --user 0 -r -t` 성공. 같은 삼성 런처 추가 창에서 `간병수첩` 제목과 `오늘 할 일과 복용 기록을 확인할 수 있어요.` 표시를 확인했다. 기존 오류 문구는 표시되지 않았다. 두 번째 위젯 추가는 취소했다.
- 기존 Flutter 위젯 시험 9개와 Android arm64 debug 빌드 통과.
- 백업 진행 중 읽기·연락, 입력 보호와 큰 글자·터치 영역을 포함한 기존 Flutter 시험 25개 통과.
