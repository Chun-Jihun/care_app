## 2026-11-04: UI/UX 1~3차와 사용자 선택 옵션

이번 1~3차는 사용자 사례 분석에서 합의한 **UI/UX 개발 순서**다. 앞의 코드 품질 계획 P3(네이티브 자원 반환·최고 메모리·시간대 정책)를 완료했다는 뜻이 아니다.

- **1차:** 기기별 표시 설정 모듈과 설정 화면을 추가했다. 큰/굵은 글자·고대비·큰 버튼·동작 줄이기·저사양 모드·사진 미리보기·홈 표시·최근 입력 선택을 저장 후 적용하며 실패하면 이전 값을 유지한다. 시스템 접근성 설정은 약화하지 않는다. 복약 입력의 자동 ‘복용함’ 기본값을 제거하고 수첩·실제 시각·같은 날 기록 및 동일 입력 분 중복 확인을 표시한다. 필수 표시와 입력 안내, 녹음 문구 대비, 저장 상태를 보완했다.
- **2차:** 홈 약은 사용자 등록 다음 확인 시각순으로 정렬하고 전체 목록·상세·실제 복약 입력을 구분했다. 최근 기록·합계·도우미·간병인 상태 홈 표시를 선택하며, 수첩별 음식·활동 이름만 직접 선택할 수 있다. 유형 필터를 전체 목록 선택으로 바꾸고 기록 카드의 주요 이름·상태를 별도로 표시했다. 홈과 편집 화면에서 연락 메뉴에 접근할 수 있고, 좁은 화면·큰 글자에서는 접근성 이름을 가진 아이콘으로 배치한다.
- **3차:** 320px 작은 화면·200% 글자·키보드·옵션 조합·OS 설정 유지·버튼 대비/터치 영역/이름·복약 미선택·중복 취소·수첩별 후보 분리·홈 숨김 후 일기 열람을 회귀 검증했다. 긴 폼 오류는 저장 버튼 가까이에 고정하고 완료 안내가 다음 작업 버튼을 덮지 않도록 했다. 기존 다섯 언어·초안·백업·잠금·의료 보류 시험도 유지했다.

설정은 `DevicePreferences`를 통해 보안 저장소의 `app.ui_preferences`에 보관한다. 환자 데이터·백업·인증 상태와 분리되어 잠금 화면에도 적용되고 기록 전체 삭제 후에도 유지한다. DB/백업 스키마를 변경하지 않는다. 저사양 모드는 UI 표시 비용을 줄이며 사진 원본이나 AI 추론 메모리 정책을 변경하지 않는다. 의료 안전·OCR 확인·챗봇 진입 경고는 끄는 옵션으로 제공하지 않는다.
