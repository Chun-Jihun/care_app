# AI 출처 확인·입력 검토 UI 사전 시험

2026-09-11 사용자 요청. 구현 전에 아래 실패 경계와 검증 항목을 정의한다.

| 실패 | 구현 원칙 | 시험 |
|---|---|---|
| 비활성 언어 메뉴로 언어가 바뀜 | 잠금 화면과 설정의 공통 메뉴는 보이되 조작할 수 없고 준비 중임을 설명. 기존 선택과 번역 자산 보존 | 두 화면에서 탭해도 선택창과 설정 변경 없음, 기존 선택 재시작 시 유지 |
| 내 기록을 의료 문서인 것처럼 표시 | 기록 출처와 의료 문서를 구분. 현재 승인된 의료 KB가 없으므로 의료 문서는 미연결 안내만 표시 | 실제 기록의 항목·시각·버전·내용 확인, 보류 답변에 가짜 문서·인용 없음 |
| 수정된 값을 과거 답변의 발췌로 오인 | 답변에 저장된 ID·버전을 대조. 불일치·삭제는 명시하고 발췌 표시 보류 | 수정·삭제·백업 제외 후 잘못된 발췌 없음 |
| 근거 화면이 다른 환자 또는 잠금 후에도 노출 | 인증된 Navigator 안에서 열고 수첩·잠금 상태를 재검사 | 잠금·수첩 전환 시 출처 원문 숨김 |
| OCR 오인식 또는 추가 메모가 자동 저장됨 | 원본 사진을 대조하며 본문 수정과 선택 메모 입력. 확인은 편집기로 전달만 하고 기록 저장은 사용자가 수행 | 수정·메모 전달, 결과 도착/취소 시 기록 불변 |
| OCR 원문과 수정본 혼동·내용 잘림 | 인식 원문을 별도로 펼쳐 비교, 본문과 메모 합산 길이 제한, 초과 시 반영 차단 | 원문 불변, 공백 본문·길이 초과 차단, 입력 중 취소 보존 |
| 작은 화면·큰 글씨에서 버튼/입력칸 접근 불가 | 줄바꿈 가능한 제목·스크롤 구성, 명확한 버튼 이름 | 320px·글자 2배 UI 시험 |

모델·프롬프트·검색 조건·의료 보류 정책과 DB/백업 형식은 변경하지 않는다.
의료 문서의 실제 발췌 연결은 임상 승인 KB와 주장별 인용 계약이 준비된 후 연결한다.
그때 자료명·기관·발행/개정일·페이지/절·근거문장·원문 링크·검수일을 모두 제공해야 한다.
