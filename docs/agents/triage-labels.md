# Triage labels

| 스킬의 역할 | GitHub 라벨 | 의미 |
|---|---|---|
| `needs-triage` | `needs-triage` | 담당자의 초기 분류가 필요함 |
| `needs-info` | `needs-info` | 재현 정보나 요구사항의 추가 확인을 기다림 |
| `ready-for-agent` | `ready-for-agent` | 명세와 완료 조건이 정리되어 에이전트가 구현할 수 있음 |
| `ready-for-human` | `ready-for-human` | 사람의 판단이나 직접 작업이 필요함 |
| `wontfix` | `wontfix` | 처리하지 않기로 결정함 |

이슈를 분류할 때 이 표의 라벨을 사용하고, 동일한 의미의 별도 라벨을 만들지 않는다. 개발 작업 라벨은 의료 근거의 임상 검수·승인 상태와 별개다.
