# 다국어 UI 구현 및 안전 검증

사용자 승인 범위: 한국어, 영어, 일본어, 중국어 간체 및 번체. 앱 내부에서 선택하고 재실행 후에도 유지한다. 기존 설치의 기본값은 한국어다.

## 구현 전 실패 시나리오와 검증 기준

- 언어 변경으로 기록·초안·암호화 키·보관기간·환자 선택이 달라짐: 기존 저장값을 비교하고 열린 편집기와 잠금 상태가 유지되는지 검증한다.
- 환자 별칭이나 메모가 UI 문구와 같아서 번역됨: 개발자가 지정한 문구·필드/선택지 메타데이터만 번역하며 사용자 입력은 그대로 표시한다. 동일한 문자열을 입력한 회귀 사례를 둔다.
- 번역 또는 변수 누락: 다섯 언어의 키와 자리표시자 집합을 검사하고 앱 소스의 번역 호출과 대조한다. 런타임 외부 번역 서비스는 사용하지 않는다.
- 잠금 화면에서 언어를 바꿀 수 없거나 저장 실패에도 변경된 것으로 표시됨: 잠금 화면과 설정에 선택기를 제공하고 기기 보안 저장소 저장 성공 후 적용한다. 알 수 없는 저장 언어는 한국어로 처리한다.
- 알림 재예약이 중복되거나 민감정보가 노출됨: 같은 알림 ID와 시간을 유지하며 문구에 언어만 반영한다. 이미 표시되었거나 시간이 지난 대기 알림은 그대로 두고, 잠긴 동안 변경한 언어는 다음 잠금 해제 시 예약에 적용한다.
- 번역이 진단·처방·AI 응답 제공으로 오인됨: 기존 안전 안내와 AI 미연결 상태를 유지한다. 언어는 국가 설정이 아니며 119는 대한민국 번호임을 표시한다.
- 긴 영문 및 큰 글꼴로 버튼이 잘림: 작은 화면과 큰 글꼴의 주요 화면을 다섯 표기로 렌더링하고 오버플로를 검사한다.
- 날짜·시간의 실제 값이 변함: 표시만 로케일에 맞추고 저장값·백업 형식·알림 시각을 유지한다.

## 범위

화면, 오류, 기록 항목/선택지, 날짜 선택기, 인증 사유, 향후 예약 알림을 번역한다. 사용자 입력, 기존 진료 준비 스냅샷, 기존 복원 수첩 이름, 파일명과 저장 코드/키는 변경하지 않는다. OS 자체 창과 앱 이름은 기기의 시스템 언어를 따른다. iOS 실행 검증에는 Mac/Xcode가 필요하며 현재 환경에서는 정적 설정 점검만 가능하다.

## 유지보수

한국어 원문을 키로 사용하는 명시적 번역 카탈로그를 사용한다. 개발자가 지정한 UI 문구에만 조회를 적용하며 화면 전체나 사용자 데이터에 문자열 치환을 적용하지 않는다. 번역은 `mobile/lib/l10n/catalogs/*.json`에서 관리하고 생성 도구로 Dart 상수 카탈로그를 갱신한다. 로케일은 앱 인스턴스/위젯 컨텍스트에 속하며 전역 변경 가능 상태를 두지 않는다.

- 번역 528개 × 5개 표기의 키·자리표시자, JSON과 생성 상수 일치 검사를 통과했다. 개발 중 미등록 키를 assertion으로 검출한다. 화면의 한국어 리터럴을 AST로 점검해 번역 호출 또는 명시적 오류 이외에 남은 문구가 없는지 확인했다.
- `test/localization_test.dart`: 저장 실패 시 기존 언어 유지, 잠금 해제 전 선택·재시작, 사용자 원문과 중괄호 보존, 번역 항목명 검색, 인증 설정·기록·알림 ID/시각 보존을 검증했다.
- 다섯 표기에서 320×640 화면과 200% 글꼴로 잠금 화면의 언어 선택, 주요 탭, 대화, 백업, 작성 중 언어 변경을 검증했다. 영어의 식사·복약·활동·생활 선택지도 추가 검사했다. 발견된 선택창 높이·날짜/건수 행·긴 선택지의 넘침을 수정했다.
- 알림 어댑터 시험에서 미래 알림의 언어별 제목·본문 변경, 시각과 ID 유지, 이미 시간이 지난 대기 알림 보존을 검증했다. 실제 OS의 배달·인증·권한창에 대한 다국어 시험을 수행한 것은 아니다.
- Android XML, iOS의 다섯 `InfoPlist.strings` 파일과 Xcode 리소스 연결을 정적으로 확인했다. Android release APK를 빌드했다. 현재 APK는 기존 개발용 서명 설정을 사용한다.
- 이전 Android 실기기 수첩·사진·백업은 수정하지 않았다. 다국어 버전의 실기기 확인과 iOS 빌드·실행, 원어민의 전체 번역 감수는 남아 있다.
