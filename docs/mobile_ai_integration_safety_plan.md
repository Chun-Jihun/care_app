2026-09-11. 요구사항 원본은 `caregiving_notebook_requirements.md`이다.
의료 근거/임상 승인 상태를 변경하지 않고 기기 내부 모델 실행을 앱의 기록 기능에 연결한다.

| 실패 | 구현 경계 | 사전/회귀 시험 |
|---|---|---|
| 다른 수첩 또는 잠금 전 작업 결과가 나타남 | 호스트가 선택 수첩과 세션을 고정, 잠금·전환·삭제 시 취소하고 늦은 결과 폐기 | 지연된 가짜 엔진으로 전환/잠금 경합 재현 |
| 모델이 약 변경·진단·근거 없는 설명을 생성함 | 챗봇 모델 출력은 조회 필터로만 파싱, 원문 기록은 호스트가 복사, 의료 설명은 보류 | 의료·지시문 공격·잘못된 JSON·모호한 날짜·외부 수첩 요청 |
| OCR/음성의 틀린 수치가 확정 기록에 바로 저장됨 | 원본을 대조할 수 있는 편집 가능한 초안, 명시적 사용자 반영/저장 | 결과 도착만으로 저장소 불변, 취소 시 기존 입력 보존 |
| 마이크/사진 원문이 파일·로그·외부 서버에 남음 | 모델은 로컬 실행, 음성은 길이를 제한한 메모리 스트림, 사진은 기존 암호화 원본 사용 | 권한 거절·중단·잠금 시 녹음 종료, 원문 로그 없음, 네트워크 권한/실행 경로 검사 |
| 변조·불완전한 모델 또는 지원하지 않는 기기 | 모델별 고정 manifest/hash, 원자적 설치, 실패 시 기본 기록 기능 유지 | 누락/변조/취소/지원 불가/메모리 오류/중복 실행 |
| 추론이 화면을 멈추거나 계속 자원을 사용함 | UI isolate 밖에서 실행, 동시에 한 작업, 세션 취소/시간/입력 크기 제한 | 처리 중 화면 조작, 동시 실행 차단, 종료 시 모델 자원 해제 |
| 무음이나 잡음을 발화로 기록함 | 음성 구간 검출 선행, 음성 없는 입력은 빈 초안, 종료 설정은 검증된 기본값 | 무음·음성·조용한 발화 대조, 중간 EOS 임의 허용 금지 |
| 학습 가중치가 변환에서 손상됨 | 원본/어댑터/변환 도구/출력 해시 보존, 변환 모델을 실제 실행해 대조 | 합성 조회·OCR·공개 음성 smoke 및 의료/경계 회귀 |

챗봇은 현재 검증된 Qwen3.5-2B SFT의 조회 필터 추출을 우선한다. 출력 기반 증류를
최종 선택으로 확정하지 않는다. OCR은 학습한 PP-OCRv5 CTC head, 음성은 학습한
Whisper small의 모바일 실행 변환을 우선한다. 런타임과 변환 과정은 별도 문서/잠금 파일에 남긴다.

실제 Android 연결 기기와 Mac 사용 가능 여부에 따라 기기 실행 검증과 iOS 빌드가 제한될 수 있다.
코드/빌드/합성 실행 확인과 실제 간병 자료·임상·모바일 성능 승인을 분리해 보고한다.

## 2026-09-23: 약물 연결·평가·배포 준비의 선행 실패 시나리오

구현 전 정의한 회귀 조건:

- 제품은 이름 유사도로 자동 확정하지 않는다. 사용자가 제품명·업체·품목코드를 확인한다. 확인은 수첩·약 버전·자료 버전에 묶이며 약 수정/보관/자료 변경 후 다시 필요하다.
- 확인 정보는 암호화 DB에 저장한다. 백업에는 약과 처방 기록을 보존하되 제품 확인 권한은 복사하지 않는다. 복원된 약은 다시 확인한다.
- 미검수/만료/손상 자료, 미확정 제품, 불완전 조회, 지원하지 않는 DUR 유형은 안전 판정으로 바뀌지 않는다. 결과 없음도 안전 판정이 아니다.
- 병용 관계는 정확한 양쪽 품목코드로 대조한다. 효능군 중복은 검수된 공식 그룹 대조 규칙이 확보되기 전까지 제품별 주의 원문만 제시한다. 조건·예외를 보존하며 나이·임신 여부·용량을 추론하거나 투약 변경을 권하지 않는다.
- 잠금/수첩 전환/약 수정/취소 중 완료된 비동기 결과는 폐기한다. 결과 일부가 잘려도 완전 조회로 표시하지 않는다.
- 검색 평가, 근거 ID 선택 모델 평가, OCR/ASR 입력별 오류 평가는 분리한다. 합성/기술 평가 통과를 임상 승인으로 기록하지 않는다.
- 설치 취소/오류는 활성 자료를 유지한다. 로딩을 자료 없음으로 오표시하지 않는다. 출시 빌드에 디버그 서명 자동 대체를 허용하지 않는다.
- 실기기·장시간·업데이트·iOS 실행 및 임상 검수는 배포 직전의 별도 검증으로 남긴다. 자동 보고서는 미수행 항목을 통과 처리하지 않는다.
