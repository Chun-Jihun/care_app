<summary>Android 네이티브 회귀 사례</summary>

- Android release에서 알림 아이콘이 리소스 축소로 제거되면 초기화와 권한 요청까지 실패한다. release APK 리소스 테이블에 `drawable/ic_notification`이 남는지 확인하고 OS 권한 거부·허용과 예약 알림 표시를 재검증한다.
- 중첩 Navigator의 Android 시스템 뒤로가기가 앱을 종료하면 사진 상세에서 기록 화면으로 돌아올 수 없다. 위젯의 `handlePopRoute`와 에뮬레이터 KEYCODE_BACK으로 회귀 검증한다.
- Android의 기본 시간대 ID `GMT`가 축약 시간대 DB에 없어 알림 초기화가 실패하는 현상을 재현했다. 전체 IANA 별칭 DB에서 GMT·Asia/Seoul을 검사하고 기기의 알림 흐름을 다시 실행한다.
- OS 인증 취소를 저장 공간 오류로 표시하지 않는다. 취소·미등록·OS 인증 실패는 인증 실패로 반환하고 PIN 대안을 유지한다.
- 잠금 중 루트 Navigator의 삭제 확인창·날짜 선택창이 남으면 사적인 UI가 재노출될 수 있다. 확인창을 연 상태에서 잠글 때 대화상자가 사라지는 회귀시험을 정의하고 모든 인증 후 대화상자를 인증된 Navigator에 연결한다.

### 대화 진입 안내

| 실패 | 방어·시험 |
|---|---|
| 안내를 확인하기 전에 기록·입력·AI 실행이 가능함 | 확인 전에는 ChatBody를 생성하지 않음. 입력란·기존 대화가 숨겨지고 AI 호출이 없는지 검사 |
| 바깥 영역 탭이나 뒤로가기가 안내를 우회함 | 바깥 탭으로 닫지 않음. 돌아가기·시스템 뒤로는 진입 취소로 처리 |
| 재진입 시 안내가 생략되거나 화면 갱신마다 중복됨 | 확인은 ChatPage 한 인스턴스에만 보관. 닫고 재진입할 때 표시, 일반 갱신·하위 화면 복귀 시 중복 없음 |
| 안내 중 잠근 뒤 확인하면 대화가 다시 열림 | 인증 Navigator 안의 팝업과 세션 재검사. 잠금 시 팝업·대화 화면 제거 |
| 작은 화면·큰 글씨에서 본문 또는 동작을 읽지 못함 | 스크롤 가능한 팝업과 줄바꿈 가능한 버튼. 기존 다섯 언어의 320×640/200% UI 시험 |

AI 오류 가능성·원본 대조, 의료진이나 약사에게 확인할 영역, 응급 연락, 현재의 기록 조회 범위를 안내합니다. 확인은 현재 화면 인스턴스에 적용됩니다. [앱 사용 안내](mobile_current_guide.md#기록-조회와-ai)

## 접근성과 번역

현재 언어 선택 메뉴는 잠금 화면과 설정에서 비활성화합니다. 저장된 언어와 다섯 카탈로그는 보존합니다. 아래에서 언어 변경 자체를 다루는 사례는 재활성화와 카탈로그 변경 시 확인합니다.

- 언어 변경으로 기록·초안·암호화 키·보관기간·환자 선택이 달라짐: 기존 저장값을 비교하고 열린 편집기와 잠금 상태가 유지되는지 검증한다.
- 환자 별칭이나 메모가 UI 문구와 같아서 번역됨: 개발자가 지정한 문구·필드/선택지 메타데이터만 번역하며 사용자 입력은 그대로 표시한다. 동일한 문자열을 입력한 회귀 사례를 둔다.
- 번역 또는 변수 누락: 다섯 언어의 키와 자리표시자 집합을 검사하고 앱 소스의 번역 호출과 대조한다. 런타임 외부 번역 서비스는 사용하지 않는다.
- 잠금 화면에서 언어를 바꿀 수 없거나 저장 실패에도 변경된 것으로 표시됨: 현재 기본 검증은 잠금 화면과 설정에서 비활성 메뉴를 확인한다. 선택을 재개하는 빌드에서는 기기 보안 저장소 저장 성공 뒤 적용한다. 알 수 없는 저장 언어는 한국어로 처리한다.
- 알림 재예약이 중복되거나 민감정보가 노출됨: 같은 알림 ID와 시간을 유지하며 문구에 언어만 반영한다. 이미 표시되었거나 시간이 지난 대기 알림은 그대로 두고, 잠긴 동안 변경한 언어는 다음 잠금 해제 시 예약에 적용한다.
- 번역이 진단·처방·AI 응답 제공으로 오인됨: 기존 안전 안내와 AI 미연결 상태를 유지한다. 언어는 국가 설정이 아니며 119는 대한민국 번호임을 표시한다.
- 긴 영문 및 큰 글꼴로 버튼이 잘림: 작은 화면과 큰 글꼴의 주요 화면을 다섯 표기로 렌더링하고 오버플로를 검사한다.
- 날짜·시간의 실제 값이 변함: 표시만 로케일에 맞추고 저장값·백업 형식·알림 시각을 유지한다.

## 기기 AI와 근거

| 실패 | 구현 경계 | 사전/회귀 시험 |

| 추론이 화면을 멈추거나 계속 자원을 사용함 | UI isolate 밖에서 실행, 동시에 한 작업, 세션 취소/시간/입력 크기 제한 | 처리 중 화면 조작, 동시 실행 차단, 종료 시 모델 자원 해제 |
| 무음이나 잡음을 발화로 기록함 | 음성 구간 검출 선행, 음성 없는 입력은 빈 초안, 종료 설정은 검증된 기본값 | 무음·음성·조용한 발화 대조, 중간 EOS 임의 허용 금지 |
| 학습 가중치가 변환에서 손상됨 | 원본/어댑터/변환 도구/출력 해시 보존, 변환 모델을 실제 실행해 대조 | 합성 조회·OCR·공개 음성 smoke 및 의료/경계 회귀 |

### 약물 자료 연결과 배포 준비

- 제품은 이름 유사도로 자동 확정하지 않는다. 사용자가 제품명·업체·품목코드를 확인한다. 확인은 수첩·약 버전·자료 버전에 묶이며 약 수정/보관/자료 변경 후 다시 필요하다.
- 확인 정보는 암호화 DB에 저장한다. 백업에는 약과 처방 기록을 보존하되 제품 확인 권한은 복사하지 않는다. 복원된 약은 다시 확인한다.
- 미검수/만료/손상 자료, 미확정 제품, 불완전 조회, 지원하지 않는 DUR 유형은 안전 판정으로 바뀌지 않는다. 결과 없음도 안전 판정이 아니다.
- 병용 관계는 정확한 양쪽 품목코드로 대조한다. 효능군 중복은 검수된 공식 그룹 대조 규칙이 확보되기 전까지 제품별 주의 원문만 제시한다. 조건·예외를 보존하며 나이·임신 여부·용량을 추론하거나 투약 변경을 권하지 않는다.
- 잠금/수첩 전환/약 수정/취소 중 완료된 비동기 결과는 폐기한다. 결과 일부가 잘려도 완전 조회로 표시하지 않는다.
- 검색 평가, 근거 ID 선택 모델 평가, OCR/ASR 입력별 오류 평가는 분리한다. 합성/기술 평가 통과를 임상 승인으로 기록하지 않는다.
- 설치 취소/오류는 활성 자료를 유지한다. 로딩을 자료 없음으로 오표시하지 않는다. 출시 빌드에 디버그 서명 자동 대체를 허용하지 않는다.
- Android 실기기·장시간·업데이트와 임상 검수는 별도 검증으로 남긴다. iOS 기기 검증은 후속 지원에 포함한다. 자동 보고서는 미수행 항목을 통과 처리하지 않는다.

## 출시 안전 평가

검증 자료는 공개·합성 개발 사례, 사용자 승인 자료, 임상 검수 평가 세트로 구분합니다. 의료 정확성 수치와 출시 판단에는 [제품 요구사항의 검증 기준](caregiving_notebook_requirements.md#검증과-출시)을 적용합니다.

| 실패 시나리오 | 필요한 방어 | 필수 시험 |
|---|---|---|
| 흐리거나 잘린 처방전에서 약 이름·용량·횟수를 잘못 추출 | 필드별 신뢰도와 원문 위치 표시, 사용자 확인 전 미확정 상태 유지 | 저화질, 반사, 일부 가림, 여러 약 혼재 및 인쇄 형식 변화 이미지에서 자동 확정 0건 |
| 음식 사진을 잘못 인식해 섭취 가능하다고 단정 | 사진 결과를 후보 음식명으로만 사용하고 재료·조리법·섭취량을 추가 확인 | 혼합식, 소스가 가려진 음식 및 식별 불가 이미지에서 안전성 확정 0건 |
