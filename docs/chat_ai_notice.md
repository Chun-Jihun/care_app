# 챗봇 진입 시 AI 이용 안내

2026-09-11 사용자 요청. 신규 대화창 진입마다 확인하며, 같은 대화창에서 근거·음성 입력 화면을 다녀온 경우에는 반복하지 않는다. 확인 상태를 기기 설정에 영구 저장하거나 책임 면제 동의로 취급하지 않는다.

## 구현 전 실패 시나리오와 시험

| 실패 | 방어·시험 |
|---|---|
| 안내를 확인하기 전에 기록·입력·AI 실행이 가능함 | 확인 전에는 ChatBody를 생성하지 않음. 입력란·기존 대화가 숨겨지고 AI 호출이 없는지 검사 |
| 바깥 영역 탭이나 뒤로가기가 안내를 우회함 | 바깥 탭으로 닫지 않음. 돌아가기·시스템 뒤로는 진입 취소로 처리 |
| 재진입 시 안내가 생략되거나 화면 갱신마다 중복됨 | 확인은 ChatPage 한 인스턴스에만 보관. 닫고 재진입할 때 표시, 일반 갱신·하위 화면 복귀 시 중복 없음 |
| 안내 중 잠근 뒤 확인하면 대화가 다시 열림 | 인증 Navigator 안의 팝업과 세션 재검사. 잠금 시 팝업·대화 화면 제거 |
| 작은 화면·큰 글씨에서 본문 또는 동작을 읽지 못함 | 스크롤 가능한 팝업과 줄바꿈 가능한 버튼. 기존 다섯 언어의 320×640/200% UI 시험 |

## 안내 내용

- AI가 내용을 잘못 이해하거나 틀린 답변을 할 수 있으므로 중요한 내용은 원본 기록·근거를 확인한다.
- 의료진을 대신하지 않고 진단·처방·치료 결정을 제공하지 않는다. 약의 복용·중단·용량 변경 및 약·건강보조제 병용은 의료진 또는 약사에게 확인한다.
- 갑작스러운 악화나 응급상황에서는 대화를 기다리지 말고 의료기관·현지 응급전화에 연락한다. 119는 대한민국 번호임을 밝힌다.
- 현재 지원은 수첩 기록 조회이며 검수된 의료 문서가 연결되기 전에는 의료 질문에 답하지 않는다.

팝업은 이용 안내이며 기존 위험 규칙·의료 답변 보류·근거 확인 정책을 대체하지 않는다. 모델·프롬프트·DB·백업 형식은 변경하지 않는다.
