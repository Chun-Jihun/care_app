# 추가 학습·증류 실험 기록

상태: **로컬 파일럿 학습·증류·학습 전후 평가 완료. 의료·모바일 출시 승인 아님.**

사용자가 모바일 검증보다 추가 학습·증류를 먼저 진행하도록 요청하여, 2026-09-10 기준선 실험 뒤 새로운 자료와 별도 가중치로 파일럿을 실행했다. 앱 코드와 의료 지식베이스 승인 상태는 변경하지 않았다. 실제 환자 자료와 외부 교사 API를 사용하지 않았다.

챗봇의 좁은 기록 조회 과업은 증류 모델이 가장 좋은 결과를 보였다. OCR의 합성 행 인식과 ASR의 일반 전사 CER도 개선됐지만 영어 OCR, SFT 일본어, ASR 숫자·단위 검사에서는 퇴보가 있었다. 새 가중치를 제품에 적용할 수 있는 검증 수준과 구분한다.

원본 예측 재채점·파일 해시 검사를 통과한 [전체 실행 결과 표](../experiments/ai_training_v1/results/completed-2026-09-11/results.md)와 [상세 결과 JSON](../experiments/ai_training_v1/results/completed-2026-09-11/results.json)을 보관했다. 총 19개 실행 이력 중 15개 완료, 2개 실패, 2개 중단이며 실패·중단 결과는 완료 성능에 합산하지 않았다.

## 범위와 자료

| 작업 | 기반 모델/방법 | 자료 |
|---|---|---|
| 질문 조건 추출 | Qwen3.5-2B QLoRA SFT | 새 합성 train 300 / validation 100 / test 200 |
| 출력 기반 증류 | Qwen3.5-4B → Qwen3.5-2B QLoRA | 교사 출력 중 조건 정답과 정확히 일치한 286/300 |
| 한국어·영어 OCR | korean_PP-OCRv5_mobile_rec의 최종 CTC 문자 분류층 학습 | 합성 행 이미지 train 160 / validation 40 / test 80 |
| 다국어 OCR | PP-OCRv5_mobile_rec의 최종 CTC 문자 분류층 학습 | en/ja/zh-Hans/zh-Hant train 320 / validation 80 / test 160 |
| 음성 전사 | Whisper small 다국어판 LoRA | 공개 읽기 음성 train 400 + 무음 12 / validation 80 / test 120 + 무음 12 |

OCR 영어 자료는 두 인식기에 공통이므로 모델별 실행 수를 독립적인 문서 수로 합산하지 않는다. 모든 합성 결과는 `compiler_generated_unreviewed`, `evaluation_eligible=false`다. 전체 실험은 `medical_release_gate_result=false`를 유지한다.

자료 분리·실패 조건·학습 설정은 [실험 프로토콜](../experiments/ai_training_v1/README.md)에 있다. [실행 환경](../experiments/ai_training_v1/training-environment.json), [OCR 자산 잠금](../experiments/ai_training_v1/ocr-assets.lock.json), [공개 음성 자산 잠금](../experiments/ai_training_v1/asr-assets.lock.json)을 함께 기록했다.

## 완료된 OCR 결과

학습 전후 같은 resize, 사전, decoder를 사용했다. backbone과 CTC encoder를 고정하고 최종 분류층만 3 epochs 학습했다. 저장된 분류층 가중치를 다시 불러와 후속 평가를 수행했다. 검출기, 문서 행 연결, 처방전 필드 추출은 이 실험의 평가 대상이 아니다.

| 인식기 / test | 공백까지 원문 일치: 이전 → 이후 | 숫자·단위 문자열 검사: 이전 → 이후 | 정규화 CER |
|---|---:|---:|---:|
| 한국어·영어 80행 | 62 → 76 | 71 → 80 | 양쪽 0% |
| 다국어 160행 | 105 → 149 | 148 → 160 | 양쪽 0% |

CER은 공백과 대소문자를 정규화한다. 개선은 주로 공백과 단위 표기이며, 처방자료의 의학적 정확도 향상으로 해석하지 않는다. 숫자·단위는 대소문자를 구분하는 문자열 multiset 검사로, 단위의 의미나 다른 행과의 연결까지 검증하지 않는다.

언어별 공백 포함 원문 일치는 한국어 인식기에서 ko 24/40 → 39/40, en 38/40 → 37/40이다. 다국어 인식기는 en 36/40 → 34/40, ja 23/40 → 37/40, zh-Hans 27/40 → 40/40, zh-Hant 19/40 → 38/40이다. 전체 개선에도 영어의 일부 표기가 나빠졌으므로 전 언어 성능 향상이라고 주장하지 않는다.

가중치는 다음 실행 폴더의 `ctc-head.pdparams`에 저장했다. 해당 head를 같은 원본 모델/사전/구성에 적용해야 하며 독립적인 모바일 추론 파일이 아니다.

- `data/ai-training-v1/runs/ocr-ko-head-sft-v2/`: 학습 파라미터 1,445,587, optimizer update 60회.
- `data/ai-training-v1/runs/ocr-multi-head-sft-v1/`: 학습 파라미터 2,224,585, optimizer update 120회.

## 챗봇 학습·증류와 비교 결과

4B 교사의 train 300개 출력은 모두 JSON 계약을 지켰고, 조건 추출은 286개가 정답과 정확히 일치했다. host의 양끝 공백 처리와 원본 조회까지 포함한 결과는 298/300이었다. 증류 자료에는 조건 추출 정답과 일치한 286개만 사용한다. 언어별 채택 건수는 ko 54, en 60, ja 52, zh-Hans 60, zh-Hant 60이다.

SFT는 결정적 정답 300개, 증류는 검증된 교사 원문 286개를 각각 학습했다. 증류 corpus가 gold SFT와 크기·선택 구성·JSON 키 순서와 공백 표기까지 다르므로 차이를 순수한 학습 알고리즘의 우열로 해석하지 않는다. 학습 대상은 의도/날짜/시간/항목과 의료 질문 보류이며 의학 지식이나 처방 결정을 학습하지 않는다.

정답 기반 학습과 증류를 모두 완료했다. 각 학습 파라미터는 8,409,600개이며 두 epochs를 실행했다. 정답 기반은 76 updates / 약 25.6분, 증류는 72 updates / 약 24.2분이다. 두 가중치는 각각 `data/ai-training-v1/runs/chat-2b-sft-v1/adapter/`, `data/ai-training-v1/runs/chat-2b-distill-v1/adapter/`에 저장하고 파일 해시와 실제 가중치 변화를 확인했다. 별도로 불러온 adapter로 평가했으며, 결과 생성기도 원본 예측을 다시 채점한다.

| 새 분할 / 지표 | 원본 2B | SFT 2B | 증류 2B |
|---|---:|---:|---:|
| validation 100건 조건 추출 일치 | 82 | 100 | 100 |
| validation 100건 최종 결과 일치 | 89 | 100 | 100 |
| test 200건 조건 추출 일치 | 111 | 172 | 200 |
| test 200건 최종 결과 일치 | 149 | 176 | 200 |

최종 결과는 프로그램이 원본을 조회한 뒤 상태·기록 ID·값을 함께 비교한 것이다. 모델은 질문에서 조건만 추출하며 기록 값, 의료 내용 또는 대화 답변을 자유 생성하지 않는다. 모든 신규 validation/test 출력은 JSON 계약을 지켰다. test의 의료 질문 보류 40건은 세 모델 모두 기대 결과와 일치했으므로 이 항목에서 학습으로 추가 개선됐다고 주장하지 않는다.

| test 언어 / 각 40건 최종 결과 | 원본 | SFT | 증류 |
|---|---:|---:|---:|
| 한국어 | 21 | 28 | 40 |
| 영어 | 30 | 40 | 40 |
| 일본어 | 34 | 28 | 40 |
| 중국어 간체 | 32 | 40 | 40 |
| 중국어 번체 | 32 | 40 | 40 |

SFT의 최종 오류 24건은 한국어·일본어에서 명시된 날짜를 `null`로 추출하여 불필요하게 보류한 사례다. 일본어 최종 조회 일치는 원본 34/40에서 SFT 28/40으로 감소했다. 증류는 이 신규 test를 모두 맞혔지만, 언어당 40건의 템플릿 자료이고 단일 seed이므로 실제 대화의 100% 정확도나 증류 방법 전체의 우위를 의미하지 않는다.

이전 기준선에서 사용하지 않고 남겨 둔 `chat-heldout.jsonl` 100건도 같은 세 모델로 비교했다. 원본은 **89/100**, SFT와 증류는 각각 **100/100**이었다. 이는 이번에 처음 개봉한 추가 개발 검사로, 학습에 사용하지 않았으며 별도 조건 추출 정답은 없으므로 최종 결과 일치만 비교한다. 세 분할 모두 기반 모델·프롬프트·decoder·후처리·입력 manifest·선택 ID가 arm 사이에서 동일했음을 확인했다.

## 완료된 음성 전사 결과

Whisper small의 q_proj/v_proj LoRA를 학습하고, 저장한 adapter를 새 원본 모델에 다시 적용해 평가했다. 학습 파라미터는 884,736개, 2 epochs / 206 updates, optimizer 실행 약 197초다. 학습 중 peak GPU 할당은 약 0.71GiB이며 전체 전처리·모델 로딩·전후 평가 시간은 포함하지 않는다. 가중치는 `data/ai-training-v1/runs/asr-small-lora-v1/adapter/`에 저장했다.

아래 CER은 정답을 분모로 다시 계산한 값이다. 공백·대소문자는 정규화하지만 숫자·구두점은 보존한다. `표시 정규화 CER`은 중국어 출력의 번체를 OpenCC로 간체로 변환한 뒤 따로 계산하며 원본 출력은 유지한다.

| 분할 / 지표 | 학습 전 | 학습 후 |
|---|---:|---:|
| validation 80발화 CER | 11.28% | 8.29% |
| test 120발화 CER | 14.11% | 9.49% |
| test 표시 정규화 CER | 11.33% | 9.22% |
| test 숫자·단위 문자열 검사 | 106/120 | 102/120 |
| 숫자·단위가 정답에 실제 포함된 test 26발화에서 일치 | 16/26 | 12/26 |
| 무음 대조군에서 빈 문자열이 아닌 출력 | 12/12 | 12/12 |

언어별 test CER은 ko 12.21% → 8.53%, en 6.33% → 5.64%, ja 20.00% → 16.29%, zh-Hans 29.37% → 11.24%다. 중국어를 같은 간체 표기로 비교하면 11.24% → 9.52%이므로 중국어의 큰 원본 점수 차이에는 표기 통일 효과가 포함된다. 전체 120발화의 공백·구두점을 포함한 원문 완전 일치는 양쪽 모두 0건이다.

**일반 읽기 음성의 문자 오류는 줄었지만, 중요한 숫자·단위 검사와 무음 처리 때문에 제품 모델로 채택하지 않는다.** 숫자 검사는 아라비아 숫자·일부 Latin 단위의 문자열 검사이며 수사와 숫자의 의미 동치나 의료 단위의 안전성을 검증하지 않는다. 정답에 해당 토큰이 없는데 예측에 새로 나타난 사례는 test에서 학습 전후 각각 4건이다.

고정한 Whisper 생성 설정에는 첫 생성 위치에서 종료 token을 금지하는 `begin_suppress_tokens=[220,50257]`가 있다. 따라서 이번 무음 실패는 모델 학습과 decoder 설정을 분리해 해석해야 한다. 음성 구간 검출(VAD)과 종료 허용 설정의 별도 비교는 아직 수행하지 않았다.

### 음성 자료와 해석 범위

FLEURS의 공개 train 분할에서 네 언어 각 100개 발화를 준비했다. 공개 validation 전체의 문장 ID·정규화 전사와 겹치는 train 예시는 제외했다. local validation/test는 문장 ID의 해시로 분리했고, 기존 평가에 쓰인 같은 언어의 문장 ID를 제외했다. 다른 언어의 병렬 번역을 과거에 평가했을 가능성은 남는다.

원 공개 train과 validation은 화자가 분리되지만, local validation과 test 사이의 화자 독립성은 현재 메타데이터로 입증하지 못한다. 실제 진료 대화·약명·고령자·소음의 도메인 학습 자료가 아니다.

길이가 다른 완전 무음도 Whisper의 길이 채움 후에는 같은 특징이 될 수 있다. 무음 결과는 학습한 대조군 확인이며 새로운 음성 환경에 대한 일반화 시험으로 표시하지 않는다. 일반 발화의 분할 간 특징 중복은 실행 중 차단한다.

실행 중 평가 함수의 정답·예측 인자 순서 오류를 발견했다. edit distance 자체는 대칭이지만 CER 분모와 `silence_hallucination` 메타데이터가 달라진다. 학습 loss와 정답 token에는 영향을 주지 않는다. 원본 예측·실행 summary를 덮어쓰지 않고 결과 생성기에서 정답 우선으로 다시 계산하며, 정정된 값은 `verification.recomputed_media_artifacts.metrics`에 둔다. OCR의 원문 일치·숫자 검사·CER 0% 결과는 그대로다. ASR의 최초 안내한 validation 11.24%는 11.28%로 정정한다.

## 자원·실행 이력과 한계

- 사용자는 GPU를 쓰는 프로그램을 계속 사용해야 한다고 응답했다. 사용자 프로그램을 종료하지 않았다. GPU 모델은 순차 실행하고 새 PyTorch 프로세스의 allocator 한도를 GPU 메모리 50%로 두었다. CPU thread는 2로 요청한다. OCR은 CPU에서 실행했다.
- 중단된 교사 실행 32개 출력은 미완료 이력으로 제외하고 새 실행에서 300개를 다시 생성했다. 마지막 SFT 추가 평가도 대화 중단으로 88/100에서 멈춰 해당 실행을 보존하고 `chat-sft-baseline-heldout-v2`에서 100건을 다시 완료했다. 실패한 최초 모델 경로 참조와 OCR bytecode cache 예외도 완료 성능에 포함하지 않는다.
- 학습용/평가용 원본과 기반 가중치의 해시를 확인하고, 새 가중치만 별도 경로에 저장한다. 실행별 source snapshot, 설치 버전, loss·gradient, adapter 변화량과 Python network audit를 남긴다.
- 기존 Python 안전·계약 회귀시험과 새 학습·집계 시험을 합쳐 127개가 통과했다. 임상 검수나 의료 출시 회귀시험 통과를 뜻하지 않는다.
- 모바일 변환·Android/iOS 실기기 검증과 의료 답변 활성화는 포함하지 않는다. 승인 의료 문서·약물 상호작용 규칙·임상 검수도 추가 학습으로 대체하지 않는다.

## 다음 개발 판단

- 챗봇 기록 조회의 다음 후보는 증류 adapter다. 실제 사용자가 작성한 다양한 비식별 질문, 상대 날짜·혼합 의도·오탈자, 수첩 격리와 모바일 변환을 새 자료로 검증해야 한다. 일반 상담 답변과 승인 근거 연결은 별도 구현·검수 대상이다.
- OCR은 영어 보존과 실제 촬영 자료의 문자인식·숫자·행 연결을 확인할 자료가 우선이다. 현재 합성 표기 개선만으로 기존 인식기를 교체하지 않는다.
- ASR은 숫자·약명·부정 표현을 평가할 동의·검수된 음성 자료, VAD와 decoder 비교가 우선이다. 일반 CER이 낮아져도 중요한 토큰 검사와 무음 실패가 남아 있어 현재 adapter를 제품용으로 채택하지 않는다.
- 이번에 개봉한 test/기존 heldout은 이후의 미사용 검증 자료로 다시 주장할 수 없다. 오류를 다음 학습에 반영한다면 새 시험 자료를 분리해야 한다.
