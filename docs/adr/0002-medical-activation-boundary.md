# 지식 파일의 기술적 설치와 의료 답변 승인을 분리한다

기존 구현과 제품 요구사항의 선택을 2026-11-03에 기록한다. 공개 기관의 자료라도 파일 해시 일치나 자동 검색 시험만으로 현재 환자에게 안전한 의학적 설명을 보장하지 못하므로, 개발 미리보기 설치와 운영 의료 허용 목록을 분리한다. 승인 문서·구조화 규칙·출처 정보·독립 검색 및 답변 회귀시험을 갖추기 전에는 운영 의료 답변을 보류한다.

자료를 받는 즉시 의료 Q&A에 사용하는 대안보다 초기 기능 범위가 작아지지만, 미검수 내용의 의료 주장과 그럴듯한 인용을 차단한다. 이 경계는 기록 조회·사용자 확인형 OCR·음성 입력 개발을 막지 않으며, 사용자 기록의 근거를 의료 문서 승인으로 혼동하지 않는다.
