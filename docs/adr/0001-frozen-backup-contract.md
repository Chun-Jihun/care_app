# DB 마이그레이션과 백업 문서 계약을 분리한다

기존 구현을 2026-11-03에 기록한다. DB 구조에서 백업 필드를 매번 유도하면 앱 업데이트가 과거 백업과 예기치 않게 충돌하므로, `BackupDocument`의 고정 계약·명시적 변환을 유지한다. DB schema 6과 선택 백업 format 3/document_version 5는 독립적으로 관리하며, 과거 합성 백업 fixture로 읽기 호환성을 검증한다.

선택 복원은 기존 수첩을 덮어쓰는 대신 ID를 바꾼 새 수첩을 추가한다. 저장 공간을 더 쓰는 대신 원본 기록·초안과 과거 처방 참조를 보존한다. 전체 교체가 필요한 예전 백업은 명시적 경고와 별도 확인을 거친다.
